# CHAOSS (chaoss)
CHAOSS (Community Health Analytics in Open Source Software) is a Linux Foundation project that develops metrics, methodologies, and software for expressing open source community health and sustainability. It provides tools like GrimoireLab and Augur for analyzing open source project health.
